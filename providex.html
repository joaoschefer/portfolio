Sobre o projeto

O projeto teve como objetivo desenvolver o front-end de uma loja virtual, transformando as necessidades da empresa em páginas claras, acessíveis e responsivas para todo o fluxo de compra. O trabalho foi concluído conforme o escopo proposto.

Destaques

  • Desenvolvimento front-end concluído
  • Catálogo e detalhes de produtos
  • Fluxo de compra e atendimento

Interface do e-commerce

Uma jornada completa de compra

As páginas foram desenvolvidas para facilitar a descoberta de produtos, apresentar informações relevantes e conduzir o cliente até a finalização da compra.
